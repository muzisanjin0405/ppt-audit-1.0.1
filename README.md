# ppt-audit-1.0.1
ppt-audit 是一个从首次听众视角审查 PPT 的技能。它会先判断听众能否理解主题、服务或产品定位、目标受众和核心主张，再检查整套内容是否形成连贯主线、每页是否表达清楚，以及图表和数据能否支撑结论。 它也会核对前后页面的数据口径、年份、单位和说法是否一致，并检查渲染后的文字溢出、字号可读性、对齐、遮挡等视觉问题。报告会区分明确问题与待确认事项，按影响排序给出修改建议；不会擅自改写 PPT。
# Skill功能结构
ppt-audit-1.0.1
│
├─ 一、技能定位
│  ├─ 面向 PPT / PPTX 的审阅、诊断与审计
│  ├─ 站在“首次接触该演示文稿的听众”视角分析
│  ├─ 优先判断主题、类别、目的和信息体系是否清晰
│  ├─ 检查页面逻辑、证据、数据一致性和视觉可读性
│  └─ 默认只提出问题与修改方向，不直接重写整套 PPT
│
├─ 二、核心审计流程
│  ├─ 1. 识别受众、目的和决策目标
│  ├─ 2. 判断整套 PPT 的主题与专业类别是否易懂
│  ├─ 3. 建立逐页“反向大纲”
│  ├─ 4. 渲染并检查每一页的视觉表现
│  ├─ 5. 提取文字、图表数据和关键数值
│  ├─ 6. 为每页提炼一句核心主张
│  ├─ 7. 模拟首次听众的理解路径和疑问
│  ├─ 8. 检查跨页面的数据、术语、日期和结论一致性
│  └─ 9. 输出按严重程度排序的可执行问题清单
│
├─ 三、审计维度
│  │
│  ├─ A. 整体主题与信息体系
│  │  ├─ 主题 / 类别是否清楚
│  │  ├─ 面向谁、解决什么需求
│  │  ├─ 核心承诺、价值或结论是什么
│  │  ├─ 与相邻类别或竞品的边界是否明确
│  │  ├─ 全篇叙事主线是否连贯
│  │  ├─ 页面顺序、分组和过渡是否合理
│  │  ├─ 方法、产品、案例和数据是否支撑核心承诺
│  │  └─ 是否回答了受众最关心的关键问题
│  │
│  ├─ B. 单页清晰度与论证
│  │  ├─ 标题是否表达结论，而非仅仅描述主题
│  │  ├─ 图表、数据或案例是否真正支撑结论
│  │  ├─ 证据到结论之间的推理是否完整
│  │  ├─ 是否存在未解释的术语、缩写或背景
│  │  ├─ 页面与前后页面的衔接是否自然
│  │  ├─ 推荐页是否说明了方案、原因、对象和下一步
│  │  └─ 听众是否需要依赖作者口头补充才能理解
│  │
│  ├─ C. 数据、日期与内部一致性
│  │  ├─ 指标定义和统计口径
│  │  ├─ 时间范围、年度、季度和预测区间
│  │  ├─ 单位、币种、数量级和百分比
│  │  ├─ 总数、分项、增长率和占比计算
│  │  ├─ 图表数值与文字描述是否一致
│  │  ├─ 来源、日期和限定条件是否完整
│  │  ├─ 跨页术语、数据和结论是否矛盾
│  │  └─ 坐标轴、比例和预测区间是否误导
│  │
│  └─ D. 视觉呈现与版式
│     ├─ 文字是否溢出、裁切或被遮挡
│     ├─ 图形、图片、标签是否重叠
│     ├─ 标题、图表、图例和坐标轴是否可读
│     ├─ 字号、对比度和行密度是否适合演示
│     ├─ 对齐、间距和分组是否清晰
│     ├─ 元素是否过于靠近页面边缘
│     └─ 视觉重点是否与页面主张一致
│
├─ 四、问题严重程度
│  ├─ 高：会改变理解、决策或对内容的信任
│  ├─ 中：造成明显理解障碍或削弱论证
│  ├─ 低：局部的清晰度、标注或一致性问题
│  └─ 待确认：存在疑点，但缺少数据或原始资料验证
│
├─ 五、标准输出结构
│  ├─ 1. 总体判断
│  │  ├─ 推断的主题、目的和核心信息
│  │  ├─ 最强优点
│  │  ├─ 最大理解风险
│  │  └─ 首次听众能否理解主题与核心承诺
│  │
│  ├─ 2. 主题与信息体系
│  │  ├─ 主题 / 类别
│  │  ├─ 目标受众
│  │  ├─ 需求与核心承诺
│  │  ├─ 一句话叙事主线
│  │  └─ 信息体系中的断点和缺口
│  │
│  ├─ 3. 逐页模拟
│  │  └─ 表格字段：
│  │     ├─ 页码
│  │     ├─ 这页想表达什么
│  │     ├─ 首次听众可能卡住的地方
│  │     ├─ 与全篇主线的关系
│  │     └─ 支撑、逻辑与修改建议
│  │
│  ├─ 4. 一致性与数据核查
│  │  ├─ 已确认的问题
│  │  ├─ 待确认的问题
│  │  ├─ 对比页面和具体数值
│  │  ├─ 不一致的原因
│  │  └─ 所需补充信息或修正方式
│  │
│  ├─ 5. 视觉呈现核查
│  │  ├─ 页面位置
│  │  ├─ 可见问题
│  │  ├─ 对阅读的影响
│  │  └─ 聚焦式修正建议
│  │
│  └─ 6. 优先修改项
│     └─ 按对理解、证据、信任和决策的影响排序
│
└─ 六、审计约束
   ├─ 所有问题必须锚定页码和可观察证据
   ├─ 区分已确认错误、信息缺失、歧义和可选优化
   ├─ 未渲染检查时，不得推断溢出、遮挡、字号等视觉问题
   ├─ 不能仅凭图表外观判断数值准确性
   ├─ 不因数值不同就直接判定为错误，需先核对口径和时间范围
   ├─ 默认不进行外部事实核查
   ├─ 不虚构数据、来源、受众反应或作者意图
   └─ 重点关注影响理解、信任和决策的问题，避免罗列纯审美偏好
